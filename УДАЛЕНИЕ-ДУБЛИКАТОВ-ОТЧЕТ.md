4. **Обновили tsconfig.json**:

## 🎯 Принцип: Один пакет = одна ответственность

**Теперь:**
- `@ts-linq/query` - единственное место для query-логики
- `@ts-linq/metadata` - единственное место для metadata
- `@ts-linq/orm` - единственное место для DbContext/DbSet
- `@ts-linq/migrations` - единственное место для миграций
- `@ts-linq/core` - только декораторы, provider abstraction, loading, batch

**Импорты стали прозрачными:**
```typescript
// ❌ ПЛОХО (было):
import { Queryable } from '@ts-linq/core'; 
// (непонятно, это реэкспорт или оригинал?)

// ✅ ХОРОШО (стало):
import { Queryable } from '@ts-linq/query';
// (сразу понятно откуда берется)
```
