    Class DbContextAbstract

    Base unit-of-work style context that orchestrates entity sets, change tracking and database provider interactions. Similar to Entity Framework's DbContext.

    Note about auto-generated DbSet properties:

    • For each registered entity class User, a property is created on the context instance using a simple pluralization of the lowercased class name: <ClassName>.toLowerCase() + 's', with a basic y → ies rule. Examples: Author → authors, Book → books, Category → categories.
    • If you want a different property name, either add your own getter that returns set(YourEntity), or use set(YourEntity) directly instead of the auto-generated property.
